# Third-party licenses

License and notice files follow upstream repository paths, such as `github.com/hyperium/tonic/` and `bitbucket.org/snakeyaml/snakeyaml/`. Monorepo package directories are preserved. Identical files are shared; versions with different license text use separate version directories.

`manifest.json` records the resolved Cargo and Dubbo interoperability-test dependencies, their upstream repositories, source locations and SHA-256 hashes. License files are copied unchanged. Rust `r-efi` includes its license in `AUTHORS`.

Refresh this inventory when dependencies change. Maven build plugins and external tools are outside the inventory. The repository's own license is in `../LICENSE`.
